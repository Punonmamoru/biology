# BIOLOGY ― 生物基礎・生物 シミュレーター学習アプリ

COMPLEXY / VECTORY / CALCULY / SEQUENCY に続くシリーズ第5作。
**図解道場**（スライダーを動かすとグラフが変わるシミュレーター）で形とわけをつかみ、**4択ラッシュ**で定着させる。

- 対象：高校2年 生物基礎／高校3年 生物（受験）
- 配布物は **`index.html` 1ファイルだけ**。外部CDN・外部フォント・通信を一切使わず、完全オフラインで動く
- 成績・氏名はどこにも送信しない。学習記録は各端末のブラウザ内（localStorage）にだけ保存される

## ステージ

| コース | ステージ | 図解道場でできること |
|---|---|---|
| 生物基礎 | B1 細胞周期とDNA量 | DNA量のグラフ（G1=2→S期で4→分裂後2）、細胞の模式図、再生アニメ、細胞数の割合から各期の長さを計算 |
| 生物基礎 | B2 血糖値の調節 | 食後の血糖値・インスリン・グルカゴン。健康／1型／2型のプリセット、食事量・分泌能力・効きやすさのスライダー |
| 生物基礎 | B3 免疫の一次応答・二次応答 | 1回目・2回目の侵入日、同じ抗原A／別の抗原B、対数軸の切替 |
| 生物基礎 | B4 光の強さと光合成 | 陽生植物・陰生植物の見かけの光合成速度、補償点・光飽和点、弱光での交差、遷移とのつながり |
| 生物基礎 | B5 生態系のバランス | ラッコの乱獲 → ウニ増加 → ケルプ減少（間接効果・キーストーン種） |
| 生物 | A1 酵素の反応速度 | v−[S] グラフ、競争的／非競争的阻害、ラインウィーバー・バーク表示、温度（熱変性の不可逆性）、pH |
| 生物 | A2 遺伝の分離比 | 乱数による交配（n＝10〜10000）で 3:1・1:1・9:3:3:1 に近づく様子、組換え価と検定交雑 |
| 生物 | A3 個体群の成長 | ロジスティック成長と指数関数的成長、被食者・捕食者の周期的変動（時間グラフ・相図） |

画面：ホーム（生物基礎／生物発展タブ）・図解道場（「やってみよう」課題つき）・4択ラッシュ（10問1ラウンド、★基礎／★★標準／★★★発展）・ミスサマリー（出席番号入りの画像保存）・用語帳・実績バッジ・引き継ぎコード。

## 使い方（生徒向け）

1. `index.html` を開く（下の「配布方法」参照）。
2. ホームでステージを選び、まず **図解道場** でスライダーを動かす。「いま何が起きているか」の文章がスライダーに合わせて変わる。「やってみよう」の課題を達成するとチェックがつく。
3. **4択ラッシュ** に挑戦する。答えるとすぐに正誤と解説が出る。「図解道場で確かめる」で該当のシミュレーターに1タップで移れる（戻るとラウンドの続きから再開）。
4. 間違えた問題は **ミスサマリー** にたまる。出席番号を入れて「画像として保存」すると、提出用の PNG 画像ができる（出席番号は保存も送信もされない）。
5. 端末を替えるときは **引き継ぎ・設定** で「コードを作成」し、新しい端末で「読み込む」に貼り付ける。

右上の ◐ ボタンで表示テーマ（自動／ライト／ダーク）を切り替えられる。

## 配布方法（教員向け）

`index.html` は1ファイルで完結しているので、次のどれでも配布できる。

| 方法 | 手順 | 向いている端末 |
|---|---|---|
| Web 公開（推奨） | GitHub Pages：リポジトリの Settings → Pages → Branch を `main`、フォルダを `/ (root)` にして保存。表示された URL を Classroom 等で配布 | すべて（特に iPhone・iPad） |
| ファイル配布 | `index.html` を Google ドライブ／Classroom／Teams／USB で配り、端末に保存してブラウザで開く | PC・Chromebook・Android |
| 校内サーバー | 校内の Web サーバーに `index.html` を置く | すべて |

- iPhone・iPad は「ファイル」アプリのプレビューではスクリプトが動かないことがあるので、Web 公開した URL を Safari で開くのが確実。ホーム画面に追加すると、アプリのように使える。
- 学習記録はブラウザごと・URL ごとに別々に保存される。ファイルの置き場所や URL を変えたときは、引き継ぎコードで移す。
- プライベートブラウズなど記録を保存できない環境でも動作する（画面を閉じると記録は消えるので、設定画面にその旨を表示する）。

## 開発

依存パッケージはない（Node.js 18 以上があればよい）。

```
src/                ソース（ES モジュール）
  main.js           エントリー（ハッシュルーター）
  styles.css        スタイル（色はすべて CSS トークン。ダークモードもここ）
  lib/              共通部品（Canvas グラフ・乱数・保存・DOM）
  models/           各ステージの数理モデル（DOM に依存しない純粋関数）
  dojo/             図解道場（スライダー・解説文・やってみよう課題）
  questions/        4択問題ジェネレーター（ステージごと）
  ui/               各画面
build.mjs           src/ を1つの index.html にまとめるビルドスクリプト
index.html          ビルド済みの配布ファイル（コミット対象）
tests/              検証スクリプト
```

```bash
node build.mjs            # index.html を作り直す（src を変更したら必ず実行してコミット）
node tests/validate.mjs   # 全問題ジェネレーター×5,000回・用語・オフライン・コントラスト・引き継ぎの検証
node tests/models.mjs     # 各モデルの「保証する形」の数値検証
node tests/smoke.mjs      # 画面のスモークテスト（Playwright がある環境のみ。なければスキップ）
```

### 問題を追加するとき

`src/questions/<ステージ>.js` の配列にジェネレーターを足す。

```js
{
  id: 'b4-xxxx', stage: 'b4', level: 2, kind: 'calc', // kind: calc / graph / term
  make(rng) {
    return {
      text: '問題文', correct: '正答', wrong: ['誤答候補', '…（3個以上）'],
      explanation: '2〜3文。「なぜそうなるか」を「〜から／ため」で1文入れる。',
      chart: { /* グラフ問題のときだけ。lib/chart.js の仕様オブジェクト */ },
      ordered: true, // 誤答候補を「よくある誤解」の順に並べたときは先頭から使う
    };
  },
},
```

同じ (ID, シード) からは必ず同じ問題ができる（ミスサマリーと引き継ぎコードはこの2つだけを保存している）。追加後は `node tests/validate.mjs` で不備 0 件を確認する。

### 用語の方針

現行の学習指導要領（2022年度〜）の教科書に合わせ、遺伝の用語は「顕性・潜性」を使う。旧用語が残っていないことは `tests/validate.mjs` が自動で確認する。
